在留资格 申请流程 指南 初学者

日本在留资格申请流程完全攻略

2026年2月7日

如果您计划在日本长期居留，无论是就业、留学、结婚还是创业，都必须了解在留资格（在留資格）制度。对于初次准备的申请者来说，专业术语可能比较陌生，流程也可能显得较为复杂。

本文将为您整理以实务为核心的申请流程，帮助您在实际申请过程中快速上手。

在留资格申请的3种类型

在留资格申请大致分为3种类型。请先确认适合自己情况的类型。

  • 在留资格认定证明书交付申请（新规）：首次入境日本的情况。通常由日本方面的代理人（公司、学校等）向出入国在留管理局提交申请。详细流程请参阅COE（在留资格认定证明书）办理流程。
  • 在留资格变更许可申请（変更）：已在日本居留中，希望变更为其他在留资格的情况。例如从留学签证变更为就业签证。
  • 在留期间更新许可申请（更新）：维持当前在留资格并延长居留期限的情况。可在居留期限届满前3个月开始申请。

1. 准备所需材料

确定了申请的在留资格和申请类型后，就进入正式准备材料的阶段。

通用必备材料

  • 在留资格申请表：可从出入国在留管理厅网站下载表格
  • 护照及在留卡：请确认有效期是否充足
  • 证件照：纵4cm × 横3cm，3个月内拍摄的照片。详细规格请参阅证件照规格指南
  • 手续费用收入印花：手续费因申请类型而异。详情请参阅申请手续费指南

根据活动内容的追加材料

根据在留资格不同，所需材料有很大差异。

在留资格主要追加材料
技术·人文知识·国际业务雇佣合同、毕业证明、简历、公司登记簿副本、财务报表
留学入学许可书、在学证明、经费支付书
日本人的配偶等婚姻关系证明、配偶的户籍副本、问卷调查表、生活照
经营·管理事业计划书、办公室租赁合同、出资金证明
永住权在职证明、课税证明、纳税证明、身元保证书

可在出入国在留管理厅官方网站确认各在留资格的所需材料清单。根据个人情况，经常会被要求提交额外材料，因此请预留充足时间进行准备。

材料准备注意事项

  • 材料之间内容的一致性：雇佣合同中的职务内容与申请表中填写的活动内容必须一致
  • 附上翻译件：外语材料必须附上日语翻译件。需注明翻译者的姓名和联系方式
  • 确认有效期：毕业证明、在职证明等需准备自签发之日起3个月以内的文件
  • 原件与复印件：原则上提交原件，但部分材料可提交复印件。如需返还原件，请在窗口提出申请

2. 向管辖的出入国在留管理局提交申请

材料全部准备齐全后，前往居住地管辖的出入国在留管理局提交申请。

申请方式

日本主要有两种申请方式。

窗口申请（亲自到场申请）

  • 原则上需要本人亲自前往申请
  • 也可通过行政书士（行政書士）等法定代理人进行代理申请
  • 受理时不收取手续费，许可时以收入印花缴纳手续费

在线申请（在留申请在线系统）

  • 自2023年3月起，可通过「在留申请在线系统（在留申請オンラインシステム）」进行在线申请
  • 适用对象：本人、所属机构职员、律师、行政书士等
  • 可申请的手续：在留期间更新、在留资格变更、再入国许可等
  • 24小时可申请，无需前往管辖管理局，非常方便
  • 使用前需要事先进行用户注册

申请地点

根据居住地址不同，可申请的管辖出入国在留管理局也不同。如果在非管辖地点申请，可能会被拒绝受理，请务必提前确认。

详细的管辖区域信息请参阅按居住地划分的出入国在留管理局申请地点指南。

申请小贴士

  • 避开高峰时段：周一、节假日后的第一天、上午时段特别拥挤。建议尽量在工作日下午前往
  • 确认受理截止时间：大部分管理局在16时截止受理。请预留充足时间前往
  • 提前检查材料：很多人在窗口因材料不齐被退回。建议制作检查清单逐项确认

申请完成后会收到受理凭证，之后进入审查阶段。

3. 审查期间与补充材料要求

各申请类型的平均审查期间

审查期间因在留资格和申请类型而异。参考出入国在留管理厅公布的处理期间统计如下。

申请类型平均审查期间
在留资格认定证明书交付1个月~3个月
在留资格变更许可2周~2个月
在留期间更新许可2周~1个月
永住许可4个月~1年以上

影响审查期间的因素如下。

  • 申请时期：4月入职季（1~3月）申请集中，审查期间可能延长
  • 所属机构类别：上市企业等类别1的企业审查相对较快
  • 材料的完成度：材料不充分时会因补充材料要求而延迟
  • 在留资格种类：永住许可比其他申请的审查期间要长得多

补充材料要求（資料提出通知書）

审查过程中，出入国在留管理局可能会要求补充材料。此时请注意以下事项。

  • 必须在通知书规定的期限内提交（通常为1~2周）
  • 超过期限可能导致不许可处分
  • 不仅仅提交要求的材料，同时附上补充说明（理由书）会更有效
  • 如果不清楚该准备什么材料或如何准备，请考虑咨询行政书士等专业人士

4. 许可后的手续（领取在留卡）

获得许可后，根据申请类型进行以下手续。

新入境者的情况

  1. 在日本领取在留资格认定证明书（COE）（通常由公司代领后通过邮寄发送给您）
  2. 在本国的日本大使馆或领事馆申请签证（通常需要3~7天）
  3. 入境日本时在机场领取在留卡（成田、羽田、关西、中部、千�的、福冈机场）

COE的有效期为自签发之日起3个月。必须在此期限内入境日本。

变更·更新申请者的情况

  1. 收到许可通知（明信片或在线通知）
  2. 前往出入国在留管理局缴纳收入印花
  3. 领取新的在留卡

变更许可的手续费为4,000日元，更新许可的手续费也为4,000日元（以收入印花缴纳）。

领取在留卡后需要做的事

  • 地址登记：领取在留卡后14天内须在居住地市区町村办理地址登记
  • 随身携带在留卡：16岁以上的外国人必须随身携带在留卡。未携带时可能被处以20万日元以下的罚款
  • 申请My Number卡：地址登记后会获得My Number（个人编号），可以申请My Number卡

常见错误与注意事项

提前了解在留资格申请中常见的错误，可以减少不必要的试错。

错误后果预防方法
在留期限届满后才申请更新非法居留（逾期居留）可在届满前3个月开始申请。请预留充足时间
申请表与附属材料内容不一致不许可或要求补充材料提交前交叉核对所有材料的日期、金额、职务内容
在留资格与实际活动不一致可能被取消在留资格仅从事就业签证许可的活动。兼职需要资格外活动许可
地址变更后未申报在留资格取消事由搬入后14天内务必在市区町村申报
护照有效期不足无法受理申请确认护照有效期长于预定居留期间

活用在线申请系统

利用自2023年3月起实施的「在留申请在线系统」，可以在不访问管理局的情况下提交申请。

在线申请的优势

  • 24小时可申请（不受管理局营业时间限制）
  • 无需前往管理局（节省交通费和等候时间）
  • 可在线查询申请状态
  • 收入印花也可在线支付（享受手续费折扣）

可在线申请的手续

  • 在留期间更新许可申请
  • 在留资格变更许可申请
  • 再入国许可申请
  • 资格外活动许可申请

使用方法

  1. 在出入国在留管理厅网站进行用户注册
  2. 使用My Number卡进行本人确认（公共个人认证服务）
  3. 将所需材料以PDF或JPEG格式附上提交申请
  4. 在线确认审查结果
  5. 许可时前往管理局领取新在留卡（或可通过邮寄领取）

总结

在留资格申请中最重要的要点如下。

  • 在留资格与实际活动内容的一致性：必须仅从事许可的活动
  • 各类材料之间内容的一致性：所有材料的内容不得相互矛盾
  • 对补充材料要求的迅速应对：请在期限内认真配合
  • 确保充足的预留时间：审查可能比预期更长，请在日程上预留余地

对于初次申请的朋友来说，比起关注单个材料，理解整体流程更为重要。从结构上把握申请流程并做好准备，可以大大减少不必要的反复和错误。
